## Selected work

- **[Pulseboard](https://github.com/kyan9400/pulseboard)** — A self-hosted uptime monitor with async checks, automatic incident recovery, an operations dashboard, Prometheus metrics, and a non-root Docker deployment.
- **[Incident Canvas](https://github.com/kyan9400/incident-canvas)** ([live demo](https://kyan9400.github.io/incident-canvas/)) — A local-first incident postmortem workspace with response metrics, timelines, owned follow-ups, validated imports, and Markdown/JSON exports.
- **[git-hotspots](https://github.com/kyan9400/git-hotspots)** — A dependency-free Go CLI that ranks risky files using Git churn, change frequency, authorship, and size, with four report formats and cross-platform releases.
- **[RepoVitals](https://github.com/kyan9400/repo-vitals)** ([live demo](https://kyan9400.github.io/repo-vitals/)) — A client-side GitHub portfolio auditor that ranks pin candidates and turns public quality signals into a focused improvement plan.
- **[OpenAPI Impact](https://github.com/kyan9400/openapi-impact)** — A Python CLI, library, and reusable GitHub Action that detects breaking OpenAPI contract changes and produces review-ready reports.
- **[micrograd-plus](https://github.com/kyan9400/micrograd-plus)** — A small automatic-differentiation engine with computation-graph visualization and optimizers, built to understand neural networks from the ground up.
- **[File Finder MCP](https://github.com/kyan9400/file-finder-mcp)** — A Python MCP server that lets compatible clients search the local filesystem by partial path.
