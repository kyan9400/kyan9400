Full-stack developer based in Moscow. I build production-minded web applications, backend services, and developer tools, with a growing focus on practical machine learning.

I work mainly with React, TypeScript, Node.js, Python, Go, PostgreSQL, and Redis. I speak Arabic, English, and Russian.

## Selected work

- **[Pulseboard](https://github.com/kyan9400/pulseboard)** — A self-hosted uptime monitor with async checks, automatic incident recovery, a customer-facing status page, Prometheus metrics, and a non-root Docker deployment.
- **[Webhook Workbench](https://github.com/kyan9400/webhook-workbench)** — A self-hosted webhook inspector with multi-channel capture, sensitive-header redaction, bounded persistence, bearer authentication, and hardened container deployment.
- **[Incident Canvas](https://github.com/kyan9400/incident-canvas)** ([live demo](https://kyan9400.github.io/incident-canvas/)) — A local-first incident postmortem workspace with response metrics, timelines, owned follow-ups, validated imports, and Markdown/JSON exports.
- **[Retry Lab](https://github.com/kyan9400/retry-lab)** ([live demo](https://kyan9400.github.io/retry-lab/)) — An interactive distributed-systems simulator for comparing fixed, exponential, full-jitter, and decorrelated retry strategies under load.
- **[git-hotspots](https://github.com/kyan9400/git-hotspots)** — A dependency-free Go CLI that ranks risky files using Git churn, change frequency, authorship, and size, with four report formats and cross-platform releases.
- **[SchemaSentry](https://github.com/kyan9400/schema-sentry)** — A dependency-free SQL migration safety analyzer with PostgreSQL-aware rules, justified suppressions, SARIF reporting, and a reusable GitHub Action.
- **[OpenAPI Impact](https://github.com/kyan9400/openapi-impact)** — A Python CLI, library, and reusable GitHub Action that detects breaking OpenAPI changes across schemas, security, media types, headers, and parameter serialization.
- **[micrograd-plus](https://github.com/kyan9400/micrograd-plus)** — A small automatic-differentiation engine with computation-graph visualization and optimizers, built to understand neural networks from the ground up.
